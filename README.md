# Mi tienda — Nova Studio

Tienda y galería adaptable para GitHub Pages (HTML, CSS y JavaScript puros).

## Archivos
- `index.html`: estructura.
- `styles.css`: diseño adaptable.
- `script.js`: productos, filtros, galería, carrito y pedido por WhatsApp.

## Personalización
Edita la constante `CONFIG` al inicio de `script.js`: cambia `whatsappNumber` por tu número real, con código de país, sin espacios (por ejemplo 51 + 9 dígitos en Perú). El número de demostración **no recibe pedidos**. Edita `PRODUCTS` para cambiar nombres, precios e imágenes y `PHOTOS` para cambiar la galería.

## Publicar gratis
En GitHub: Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save. La URL esperada es https://jlservigon-del.github.io/mi-tienda/ (solo funcionará cuando Pages termine de publicar).

Esta demostración no cobra con tarjetas, no tiene backend ni control de inventario. Las fotos se cargan desde Unsplash y requieren conexión a internet.
